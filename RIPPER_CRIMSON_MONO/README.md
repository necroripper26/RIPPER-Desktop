# RIPPER CRIMSON — Monochrome

Nuevo fondo independiente para KDE Plasma 6. La imagen **Calavera Crimson Ghost** llena toda la pantalla. Sin flores ni capas violetas. Los paneles y controles se mantienen en blanco/negro.

## Instalar

```bash
bash install.sh
```

En **Configurar escritorio > RIPPER CRIMSON** puedes habilitar un video central, elegir archivo local, ajustar ancho y opacidad. Por defecto está desactivado para que la calavera cubra el escritorio.

Las 15 barras del panel musical se animan durante la reproducción; son una visualización de actividad, **no** un espectro de amplitud real capturado del audio.

## Restaurar

```bash
~/.local/bin/ripper-crimson-restore
```

No altera paneles, configuración de monitores ni otros fondos.
